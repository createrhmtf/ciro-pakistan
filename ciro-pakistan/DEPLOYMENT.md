# CIRO Pakistan — Live Production Deployment Guide

This guide details the process of deploying the live multi-agent crisis response system to production environments.

---

## 1. Backend Deployment (FastAPI) on Render

Render is the recommended hosting platform for the FastAPI Python backend due to its native support for Uvicorn and environment-variable secrets.

### Prerequisites
1. Ensure `requirements.txt` contains all dependencies:
   ```text
   fastapi
   uvicorn
   requests
   pydantic
   python-dotenv
   google-generativeai
   firebase-admin
   ```
2. Check that `backend/main.py` binds the server port dynamically using `os.getenv("PORT", 8000)`.

### Step-by-Step Render Deployment
1. Sign in to [Render](https://render.com/) and click **New > Web Service**.
2. Connect your Git repository.
3. Configure the following service settings:
   - **Name**: `ciro-pakistan-api`
   - **Environment**: `Python 3`
   - **Root Directory**: `ciro-pakistan/backend` (or leave empty if importing a standalone backend repo)
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. Expand the **Advanced** section and add the following Environment Variables:
   - `GEMINI_API_KEY`: *Your Google AI Studio Gemini API Key*
   - `WEATHER_API_KEY`: *Your OpenWeatherMap API Key*
   - `GOOGLE_MAPS_API_KEY`: *Your Google Maps/Directions API Key*
   - `AQI_API_KEY`: *(Optional) World Air Quality Index API Key*
   - `GOOGLE_APPLICATION_CREDENTIALS`: *(Optional) Path or credentials string for Firebase Admin Service Account*
5. Click **Create Web Service**. Render will build the image, start Uvicorn, and provide a public HTTPS URL (e.g., `https://ciro-pakistan-api.onrender.com`).

## 2. Frontend Deployment (React + Vite PWA) on Vercel

Vercel is optimized for building and deploying static Vite single-page applications with integrated service worker caching support.

### Step-by-Step Vercel Deployment
1. Sign in to [Vercel](https://vercel.com/) and click **Add New > Project**.
2. Connect your Git repository.
3. Configure the project settings:
   - **Framework Preset**: `Vite`
   - **Root Directory**: `ciro-pakistan`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Add the following Environment Variable:
   - `VITE_API_URL`: `https://ciro-pakistan-api.onrender.com` (Use the URL generated by Render above)
5. Click **Deploy**. Vercel will bundle the React assets, set up edge routers, and publish your live PWA.

### PWA / Service Worker Verification
To verify the production PWA capabilities:
1. Open the deployed Vercel URL in Google Chrome or Microsoft Edge.
2. Open Chrome DevTools (`F12`), go to the **Application** tab, and select **Service Workers**.
3. Verify that the service worker registers successfully and matches the offline cache profile.
4. Click the **Install App** icon in the browser address bar to install CIRO Pakistan as a standalone desktop or mobile application.
